## لماذا؟

عند تصوير فيديو طويل (قصة، بودكاست، تقرير) يصعب حفظ النص — والنظر للهاتف يخرجك من الكادر. الحل: النص يمر أمام عينيك بجانب الكاميرا، بسرعتك أنت، وتوقف متى شئت. هذا التطبيق يفعل شيئاً واحداً ويفعله جيداً: **القراءة المريحة** — بلا إنترنت، بلا حساب، بلا إعلانات، بلا ثقل.

## الميزات

### التحرير والمكتبة
- ✍️ محرر نصوص كامل يدعم **العربية والإنجليزية والإيموجي والأرقام** مع كشف اتجاه النص تلقائياً (RTL/LTR)
- 📚 **مكتبة القصص**: جديد / حفظ / تسمية / تكرار / حذف بتأكيد، مع اقتراح عنوان ذكي من أول سطر (يتجاهل الإيموجي والزخارف)
- 💾 **حفظ تلقائي** ذكي (debounced) — كل تغيير يُحفظ خلال ثانية، وبكتابة ذرية (ملف مؤقت ثم استبدال) لا يُفسد ملفك أبداً ولو انقطعت الكهرباء في منتصف الكتابة
- 🔄 **استرجاع بعد الانهيار**: أعد فتح التطبيق وسيجد نصك كما كان، مع موضع القراءة الذي وصلت إليه
- 📥📤 استيراد/تصدير ملفات `txt` بترميز UTF‑8
- ⏱️ تقدير زمن القراءة (بالكلمات والسرعة) وعدّاد الكلمات والأحرف — مباشرة أثناء الكتابة

### وضع القراءة (Teleprompter)
- 🎞️ **تمرير ناعم كالزبدة** على أضعف جهاز — يعمل على خيوط العرض (render thread)، صفر استهلاك معالج عند التوقف
- 🖱️ سرعة 1‑100 تتغير **مباشرة أثناء القراءة** بلا أي قفزة
- 🔠 خط من 24 إلى 120 (أزرار − / + أو اختصارات)
- 📏 عرض عمود القراءة وموضع القراءة العمودي قابلان للضبط (حسب موضع الكاميرا)
- 🎯 دليل تركيز اختياري (شريط ذهبي يظلل منطقة القراءة)
- ⏳ عد تنازلي 3‑2‑1 قبل البدء
- 🪞 وضع المرآة (لمن يستخدم زجاج تيليبرومتر)
- 🚫 التحكمات تختفي تلقائياً أثناء القراءة وتظهر بتحريك الفأرة
- ▶️ علامات `[توقف 3ث]` داخل النص كتذكير بوقفاتك
- 📊 مؤشر تقدم قابل للإخفاء + النسبة المتبقية والوقت المتبقي تقديرياً
- ⌨️ اختصارات كاملة (انظر الجدول)

### الخصوصية والأداء
- 🔒 **يعمل بلا إنترنت 100%** — لا حساب، لا تتبع، لا أخطاء شبكة. نصوصك تبقى في جهازك فقط
- 📁 كل البيانات في `%APPDATA%\LATCHI Teleprompter` (قابلة للنسخ الاحتياطي يدوياً) **ولا تُحذف عند إزالة التطبيق**
- 🌙 واجهة داكنة فاخرة (كحلي + ذهبي) مريحة للعين، بأيقونات متجهات حادة على أي دقة

## التحميل والتثبيت

من صفحة **Actions** في هذا المستودع: آخر تشغيل ناجح ← Artifacts ← `latchi-teleprompter-vX.Y.Z-win-x64`:

| الملف | الوصف |
|---|---|
| `LATCHI-Teleprompter-Setup-X.Y.Z.exe` | مثبّت لكل مستخدم — **بلا صلاحيات مدير**، قائمة ابدأ + اختصار سطح مكتب اختياري |
| `LATCHI-Teleprompter-X.Y.Z-portable-win-x64.zip` | نسخة محمولة — فك الضغط وشغّل مباشرة |
| `artifact-manifest.txt` | أسماء وأحجام وبصمات SHA‑256 الحقيقية للملفات |

> يحتاج **Windows 10/11 على معالج 64‑bit** — لا يتطلب تثبيت .NET (مضمّن مع التطبيق).

## البناء من المصدر

```bash
git clone https://github.com/latchidz/latchi-teleprompter
cd latchi-teleprompter
dotnet build -c Release          # تجميع
dotnet test  -c Release          # اختبارات النواة (34 اختبار)
dotnet run --project src/LatchiTeleprompter.App -- --smoke   # فحص ذاتي شامل
```

الإنتاج الرسمي (Setup + Portable) يُبنى حصراً على **GitHub Actions** (workflow `build.yml`) — نفس الـworkflow يفحص الـexe الإنتاجي نفسه بـsmoke test قبل تغليفه.

## البنية

```
src/LatchiTeleprompter.Core      ← منطق قابل للاختبار: نماذج، مكتبة، حفظ ذري، محرك تمرير
src/LatchiTeleprompter.App       ← واجهة WPF داكنة: محرر + مكتبة + وضع القراءة + فحص ذاتي
tests/LatchiTeleprompter.Tests   ← 34 اختبار xUnit للنواة
installer/                       ← سكربت Inno Setup (مثبت بلا صلاحيات مدير)
.github/workflows/build.yml      ← البناء والفحص والتغليف على GitHub Actions
```
